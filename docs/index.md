# Global Multimodal VAE

A modular, extensible multimodal Variational Autoencoder framework: not a
model for two fixed data types, but an architecture designed so that adding
a new modality never requires touching the core.

- **New here?** Start with [Getting Started](getting-started.md).
- **Want to understand *why* it's built this way?** Read the
  [project specification](global-vae-project-specification.md) and the
  [architecture decision records](adr/index.md).
- **Want to do something specific?** Check the
  [how-to guides](how-to/add-a-modality.md).
- **Looking up a function or class?** Jump straight to the
  [API reference](reference/).

For the current release notes and feature status, see the repository's
`README.md` and `CHANGELOG.md`; this site focuses on how to use and extend
the framework, and why it's shaped the way it is.
